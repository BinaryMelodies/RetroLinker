Detailed Description

MP/M .prl file format.

Member Enumeration Documentation

◆ application_type

enum Binary::PRLFormat::application_type

The format of the generated binary.

This controls the difference between the layout of the generated binary, as well as defaults such as base address and file extension. The only ones that actually require special treatment are SPR and OVL files, the other file types are included for convenience.

Enumerator
APPL_UNKNOWN 

Unspecified.

APPL_PRL 

MP/M-80 .prl executable file.

APPL_RSX 

CP/M-80 Plus .rsx resident system extension file (unsupported).

APPL_RSM 

CP/M-80 2 .rsm resident system extension file (unsupported).

APPL_RSP 

MP/M-80 .rsp resident system process file (unsupported).

APPL_BRS 

MP/M-80 .brs banked resident system process file (unsupported).

APPL_SPR 

MP/M-80 .spr system module file (unsupported).

APPL_OVL 

CP/M-80 .ovl overlay (unsupported).
